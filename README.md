
# Student Grade Management System

## About the Project
This is a Python-based application designed to
manage student marks and calculate grades.

## Features
- Add student details
- Enter marks for three subjects
- Calculate total marks
- Calculate average marks
- Automatically assign grades
- Display student reports

## Technologies Used
- Python
- Functions
- Lists and Dictionaries
- Loops
- Conditional Statements

## How to Run
1. Install Python.
2. Download the Python file.
3. Open the terminal in the project folder.
4. Run:

python student_grade.py
